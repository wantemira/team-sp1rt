# Фронтенд кредитного кабинета

React/Vite: кабинет клиента и рабочее место сотрудника. Рабочие страницы
обращаются к API. Данные синтетические; подписание и выдача смоделированы.

## Общий запуск

Подготовьте `.env` и выполните `docker compose up --build -d --wait`
из корня репозитория. Интерфейс — http://localhost:8080.
Nginx отдаёт сборку и проксирует `/api/` в сервис `api:8000`.
[Настройки, аккаунты и основной сценарий](../README.md).

Команды из корня: `make web-dev`, `make test-web`, `make test-ui`.
Перед первым `make web-dev` выполните `make deps-web`. Браузерная проверка
использует работающий стенд, пароль и порт из `.env`.

## Разработка

Для разработки проверен Node.js 20.20. API должен быть запущен.

```bash
cd frontend
npm ci
npm run dev
```

Интерфейс — http://localhost:5173. Vite направляет `/api` на
http://localhost:8000. Для другого адреса задайте `CREDIT_API_TARGET`.

## Поведение интерфейса

- Условия продукта приходят из `/products`. При ошибке загрузки доступен повтор;
  создание заявки и ручное одобрение блокируются до получения условий.
- Черновик сохраняется на сервере. ИНН берётся из профиля клиента.
- После отправки показываются результат ФНС/БКИ, предложение и объяснение.
  Проверки синхронные; интерфейс ждёт ответ сервера.
- Согласие подтверждает сохранённые условия. При конфликте версии интерфейс
  перечитывает заявку; если загрузка не удалась, блокирует действия до обновления.
- Сотрудник видит финансовые основания и принимает решение с комментарием.
- Документы загружаются и скачиваются через API с проверкой доступа.
- Новостная лента учитывает тип бизнеса и последнюю заявку. Раскрываемые
  материалы содержат причину подбора и полный текст. Данные других клиентов
  не используются; тексты синтетические.

## Проверки

```bash
npm run lint
npm test
npm run build
npx playwright install chromium
# API должен быть запущен с тестовыми аккаунтами:
E2E_PASSWORD='пароль_стенда' npm run test:ui
```

Пароль должен совпадать с паролем аккаунтов API; значение по умолчанию —
`password123`. Браузерные тесты создают заявки и документы: используйте отдельный
тестовый стенд. `PLAYWRIGHT_BASE_URL` задаёт адрес интерфейса,
`PLAYWRIGHT_CHROMIUM_EXECUTABLE` — путь к Chromium, `FRONTEND_PORT` — порт Vite.
По умолчанию тесты используют порт 5173 и сами запускают Vite при необходимости.

Основной кредитный путь, документы, повтор ФНС, дозаполнение и ручное одобрение
проверяются на работающем API. Редкие конфликты, ошибки каталога, недоступность
источников и ограничения ручных действий проверяются также на подменённых
ответах. Авторизация остаётся настоящей. Финансовая карточка покрыта
модульными тестами и браузерной проверкой, включая мобильный экран.
